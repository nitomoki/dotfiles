# 永続的にインストールしたい apt パッケージのリスト。
# 共通の CLI ツール（tmux / ripgrep / gh / neovim など）は nix/home.nix で入れる（make switch）。
# ここに残すのは Nix より先に要るもの、OS に密着したもの、GUI アプリ。
# 新マシンでセットアップ: make setup
# 現在の差分を確認:       make packages-diff
#
# 注意: tailscale / wezterm / obsidian / steam-launcher などは
#       追加の apt source / .deb / snap が必要。本リストでカバーされない場合あり。

# --- Build & dev base ---
# コンパイラ一式は Nix にしない。Nix の cc は Ubuntu のライブラリとリンクしにくい。
# curl / git / make は Nix と dotfiles を入れる前（make setup の時点）に要る。
build-essential
clang
curl
git
make
pkg-config

# --- Language runtimes ---
# Rust は rustup で入れる。apt の cargo は古いうえ、PATH で ~/.cargo/bin より先に見つかって rustup 版を隠す。
# node / perl / ruby は Nix にしない。store が読み取り専用で npm -g、cpanm、gem install が書けないため。
# python3 は OS のツールと Claude の hook（標準ライブラリだけ）が使う。pip は使わず uv にする。
nodejs
npm
perl
python3
ruby

# --- Shell ---
# zsh はログインシェルにするので /etc/shells に載る apt 版を使う。
zsh

# --- CLI tools ---
# vim / xclip / unzip / cmake / mosh は nix/home.nix で入れる。
cpanminus

# --- LaTeX ---
latexmk

# --- Fonts / locale ---
fontconfig
fonts-noto-cjk-extra
gnome-user-docs-ja
language-pack-gnome-ja
language-pack-ja

# --- Japanese IME (mozc) ---
ibus-mozc
libm17n-0
m17n-db
mozc-utils-gui

# --- Network / remote access ---
openssh-server
tailscale
x11vnc

# --- GUI apps ---
obsidian
steam-launcher
wezterm
